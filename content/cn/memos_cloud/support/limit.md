## 2. 资源限制

为保证服务稳定与安全，MemOS 云服务对核心资源有如下限制，按照账号维度计算。

### 接口调用限制

| **接口名称** | **单次输入上限** | **单次输出上限** |
| --- | --- | --- |
| addMessage | 40,000 token | - |
| searchMemory | 40,000 token | 召回总上限：25 条（含事实、偏好、属性、事件、工具、技能） |

### 请求频率限制（QPS）

| 限制项 | 说明 |
| --- | --- |
| 建议最大 QPS | ≤ 40（每秒最多 40 次请求）；非严格限制，但高并发可能受平台处理能力影响 |
| 每分钟输入 token 总量 | 不超过 400,000 token，超出后请求将被限流 |

### 群聊场景

| 限制项 | 说明 |
| --- | --- |
| `user_id` / `agent_id` 列表上限 | 单次最多传入 20 个 ID |
| QPS 折算 | 按参与人数折算；例如传入 20 个 ID 时 ×20 折算，即每秒最多 2 次请求 |

### 知识库文档上传

| 限制项 | 说明 |
| --- | --- |
| 支持的文档类型 | PDF、DOCX、DOC、TXT、JSON、MD、XML |
| 单文件大小上限 | 100 MB、500 页 |
| 单次上传文件数量 | 不超过 20 个 |

::note
知识库还支持上传 Skill 文件，详细限制见 [知识库](/cn/memos_cloud/features/knowledge_base)。
::
